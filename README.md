# Mounika Nalliboina — Software Engineer Portfolio

Live portfolio website of **Mounika Nalliboina**, Software Engineer with 3+ years of experience specializing in full-stack feature delivery (Angular, Spring Boot), PostgreSQL database tuning, and test automation frameworks (Selenium, Playwright, Cucumber). Graduate student at UMBC.

## 🚀 Tech Stack
- **HTML5 & CSS3**: Pure modern vanilla CSS with custom tokens, glassmorphism, responsive grid & flexbox.
- **JavaScript (ES6+)**: Dynamic typing role rotator, scrollspy navigation, clipboard integration, and reveal animations.
- **Design Aesthetic**: Sleek dark mode (`#080808`, `#000000`) with electric cyan accents (`#00BFFF`).

## 🌐 Hosting on GitHub Pages
1. Push this repository to GitHub.
2. In the repository, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`!
